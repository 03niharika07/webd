BOILERPLATE CODE:

  • < !DOCTYPE html > : shows that the document that is served on the webpage supports html and the latest version of html, HTML 5.
  • < html > : root element of html page.
  • < head > : this element contains meta information about the html page.
  • < title > : this element specifies a title for the HTML page (which is shown in the browser's title bar or in the page's tab).
  • < body > : this element defines the document's body, and is a container for all the visible contents, like headings,paragraphs,images,hyperlinks,tables,lists,etc.
  • < h1 > : element that defines a large heading.
  • < p > : element that defines a paragraph.

TAGS (CONTAINERS):

The component used to design the structure of websites are called HTML tags.

1. HEAD TAG: In head tag,the things that we dont want to display on the screen, are written. Represented by head.

2. HEADING TAG: Heading Tag is used for heading. There are six heading tags tags having different sizes.

3. PARAGRAH TAG:To add paragarphs.Ignores the spaces and displays text in a paragraph form. Represented by p.

4. ANCHOR TAG: Used to add links to pages for other websites. There are 2 types of links- Absolute Link (link of other website) and Relative link (link of another file from our collection). Represented as:

5. BODY TAG: Body tag is used to add content- heading , paragraphs.The things that we want to display on the webpage are written in body tag.Represented by body.

6. BR TAG: It is used to add next line(line breaks). It has no closing tag. Represented by br.

7. IMAGE TAG: used to add images. If by mistake the link is not correct, the image will not be loaded so alt attribute is used to diplay name of the image or any related information if in case image cant be loaded. Size can be altered by using attributes like height="" or width="", recommended to change one at a time.

8. BOLD, ITALIC, UNDERLINE TAGS: used to bold , underline to make the text italic.

9. BIG AND SMALL TEXT: used to show big or small tags.

10. HR TAG: It is used to display horizontal ruler, used to separate contents. It has no closing tag.

11. SUBSRIPT AND SUPERSCRIPT TAGS: can be used to write chemical formulas or mathematical formulas.

12. PRE TAG: It is used to display text as it is (without ignoring spaces and next line).

PAGE LAYOUT TECHNIQUES:

  • There are two types of tags - semantics tag and non semantic tags.
  • Semantic tags are those which can be understood by seeing them, include tags like header, footer, main.
  • Non semantics tags are those whose meaning can't be understood by seeing them, include tags like div, span, etc.

Semantic Tags:

  • Semantic tags make the code more readable.
  • Lines of code can be written in a more structured manner.
  • Use of semantic tags is important as it improves the ranking.
  • It is a good user experience.

Semantic tags include 3 tags - header, main, footer.

Main tag includes 3 tags inside it- section, article, aside.

  1. Section Tag: For a section on your page.
  2. Article Tag: For an article on your page.
  3. Aside Tag: For content aside main content(ads).

LISTS IN HTML:

Lists are used to represent real life list data.

There are two types of lists: UNORDERED LIST and ORDERED LIST.

1. UNORDERED LIST: The data is printed in the form of bullets. 'li' stands for list item.



2. ORDERED LIST: The data is printed in a sequence (numbers, roman numerals,alphabets).


TABLES IN HTML:

Tables are used to represent real life table data.

  • tr tag is used to diplay table row.
  • td tag is used to display table data.
  • th tag is used to display table header.
  • caption tag is used to add caption.
  • thead tag is used to wrap table head.
  • tbody tag is used to wrap table body.
  • colspan attribute is used to create cells which spans over multiple columns.
